# 🚀 Day 26 – Linked List Problem Solving

Today, I focused on Linked List problem solving and worked on:

## 💻 LeetCode 148 – Sort List

The problem requires sorting a Linked List in ascending order.

Instead of converting the Linked List into an array and sorting it, I practiced solving it using Merge Sort.

## 🧠 Concepts Practiced

- Splitting a Linked List into two halves
- Slow & Fast pointers
- Recursion
- Merging two sorted Linked Lists
- Applying Merge Sort to a Linked List

## 🔍 Approach

1. Find the middle of the Linked List using Slow & Fast pointers.
2. Split the Linked List into two smaller lists.
3. Recursively sort both halves.
4. Merge the two sorted halves into one sorted Linked List.

## ⏱️ Complexity

- Time Complexity: O(n log n)
- Space Complexity: O(log n) due to recursion

## 🎯 Key Learning

I practiced how Merge Sort can be applied directly to a Linked List by combining
splitting, recursion, and merging.
