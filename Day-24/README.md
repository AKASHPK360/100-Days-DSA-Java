## 💻 Problem Solved

### LeetCode 3 — Longest Substring Without Repeating Characters

Used the Sliding Window technique with two pointers.

- `right` expands the window
- `left` shrinks the window when a duplicate appears
- Frequency array tracks characters
- Maximum valid window length is maintained

## ⏱️ Complexity

- Time: O(n)
- Space: O(1)
